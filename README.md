## 🚀 Project Overview

This repository contains the source code for my professional portfolio. It is designed to showcase my full-stack web development projects, engineering background, and professional services to prospective clients and employers. 

The UI is built around a custom "engineering blueprint" aesthetic, utilizing subtle grid backgrounds, JavaScript-driven animations, and a crisp, highly professional color palette (`#ececec` backgrounds, `#0f172a` typography, and `#0284c7` accents).

## 🛠️ Tech Stack

* **Framework:** React 18 + Vite
* **Styling:** Tailwind CSS
* **Routing:** React Router v6
* **Animations:** Framer Motion (Utilizing variant propagation for reliable, JS-driven hover states)
* **Forms:** EmailJS (Serverless contact delivery)
* **Icons:** Lucide React

## ⚙️ Key Features

* **Component-Based Architecture:** Modular UI components (`ProjectCard`, `Pricing`, `About`) for easy scaling and maintenance.
* **Animated Page Transitions:** Seamless layout rendering and buttery page transitions powered by `<AnimatePresence>`.
* **SEO Optimized:** Full OpenGraph metadata, custom favicons, and Apple Touch icon integrations optimized for social and WhatsApp sharing.
* **Session-Based Affiliate Tracking:** Captures custom URL referral parameters dynamically (`?ref=`) and stores them via `sessionStorage` to pass through to the contact form.
* **Responsive Design:** Mobile-first architecture ensuring perfect scaling from mobile devices to ultrawide desktop monitors.
